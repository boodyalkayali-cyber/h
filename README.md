# Case Files / ملفات الحالات  (Phase 1)

## التشغيل على GitHub
1. أنشئ مستودعاً **خاصاً (Private)** على GitHub (الملف يحوي مفتاح التوقيع، لا تجعله عاماً).
2. ارفع كل محتويات هذا المجلد إلى المستودع، **بما فيها المجلد المخفي `.github`**.
   إن لم يُرفع المجلد المخفي: Add file ← Create new file، واكتب الاسم `.github/workflows/build.yml` والصق محتوى الملف.
3. افتح تبويب Actions وانتظر انتهاء "Build APK" (5 إلى 10 دقائق في أول مرة).
4. نزّل التطبيق من تبويب Releases (ملف CaseFiles.apk) وثبّته على الهاتف.
5. إن فشل البناء: افتح الخطوة الحمراء، انسخ سطور الخطأ وأرسلها لي.

التحديثات اللاحقة تُثبَّت فوق النسخة القديمة دون فقدان البيانات (المفتاح ثابت).
